3. Promoções

Já existem ofertas no balcão — tipo dipirona a R$ 4,99 ou 3 por R$ 12. Cada uma precisa destes campos para aparecer no site:

Três coisas importantes sobre promoção:

  1. Promoção tem que mostrar o preço que ela substitui. Se o site mostrar só "Dipirona R$ 4,99" sem o "de R$ 7,90", o cliente não sabe que é desconto — e não existe como provar o abatimento. Ou seja: mostrar promoção é mostrar preço normal junto.
  2. Medicamento controlado não entra em promoção. A Receita Federal proíbe desconto sobre controlado. São 4 aqui: Trazodona, Fluoxetina (2) e Sertralina.
  3. Promoção vencida no site dá problema — é multa e cliente bravo no balcão. Por isso a data final é obrigatória.

Não coloque senha de API dentro do site. O site é público no GitHub. Se a API exigir senha, o caminho muda (privar o site ou usar um servidor no meio).

5. Como exportar

  1. No Dmaster: Relatórios → Estoque / Produtos → Exportar
  2. Ou: Produtos → Relatórios → Inventário
  3. Se não achar o botão: tire print da tela de listagem de produtos com preço e estoque. Eu leio o que estiver legível.

Formatos que eu leio: .csv · .xlsx · .txt · .json · ou print de tela.

6. O que acontece depois

  1. Leio o arquivo e confiro se bate com os 105 produtos do site
  2. Gero o catálogo com preço, estoque e categoria corrigidos
  3. Ligo a exibição de preço (hoje está escondida)
  4. Adiciono disponibilidade no card (sem número exato)
  5. Se vier a lista de promoções, monto os selos "de R$ X por R$ Y"
  6. Se tiver EAN, baixo foto real de cada produto
  7. Sincronizo os cards da página inicial

Tempo estimado: uma tarde de trabalho, dependendo do tamanho do arquivo.

7. Resumo para levar na farmácia

Peça uma vez só:

  1. Lista de produtos com preço e estoque
  2. Lista de promoções (se tiver), com a data final de cada uma
  3. Resposta das 4 perguntas do suporte (seção 4)
  4. Se tiver, o código de barras de cada produto

Não leve para o site: arquivo de clientes com CPF e telefone. Fica fora do site, serve só para mensagem de retomada.

Antes de publicar o site com preço, confirme:

  • Preços revisados pelo farmacêutico responsável
  • Data final de cada promoção conferida
  • Preço de Farmácia Popular separado (é regulado e diferente)
  • Controlados fora de promoção: Trazodona, Fluoxetina, Sertralina

Sobre mostrar o estoque: o site vai mostrar disponibilidade ("disponível" ou "consulte"), e não a quantidade exata. Se o site disser "12 unidades" e chegar 0 na loja, o cliente foi até lá à toa — e isso queima a confiança mais rápido do que preço errado.

Quando você alterar um preço, me avise que eu atualizo em 1 minuto.
